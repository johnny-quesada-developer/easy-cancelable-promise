## Create a CancelablePromise

A `CancelablePromise` is created like a `Promise`. The callback receives `resolve` and `reject`, and a third
parameter with the utilities of the promise. `onCancel` is the one you will use most: it registers what has to
happen when the promise is canceled.

<CodeBlock code={firstPromise} lang="ts" title="first-promise.ts" />

Without `onCancel` the promise would still be canceled, but the timer would keep running. Canceling a promise
tells everyone to stop waiting. `onCancel` is where the work itself is stopped.

## Use it like a Promise

`CancelablePromise` extends `Promise`. Everything that accepts a promise accepts it: `await`, `then`, `catch`,
`finally`, `Promise.all`. On top of that it has a `status` and a `cancel` method.

<CodeBlock code={useIt} lang="ts" title="use-it.ts" />

## Cancel a real request

The same pattern works for anything that can be stopped. For `fetch`, that is an `AbortController`.

The code that cancels does not need to know there is a request behind the promise. The promise handles its own
cleanup.

The callback can also be an `async` function. An error it throws rejects the promise.
