## Nothing to mock

A `CancelablePromise` is a real promise with no dependencies. It runs the same in Node, jsdom and the browser,
so tests use the real class.

## Test that canceling stops the work

The claim of a cancelable function is that its work stops. Assert on that, not only on the rejection.

<CodeBlock code={delay} lang="ts" title="delay.ts" />

<CodeBlock code={delayTest} lang="ts" title="delay.test.ts" />

- `status` changes as soon as `cancel` is called, so it can be asserted without awaiting anything.
- With fake timers, `getTimerCount` shows that the timer was cleared.
- The rejection carries the reason that was passed to `cancel`.

## Hand the code a promise you control

Code that receives a promise is tested by giving it one. `defer` creates a promise the test resolves, rejects,
cancels or reports progress on, at the moment it chooses.
